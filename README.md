# polbazaar.com

Coming soon page for PolBazaar, Amdavad's own bazaar. It counts down to the launch on
**Friday 1 January 2027, 11:11 AM IST** and is served by GitHub Pages on `polbazaar.com`.

| File | What it is |
| --- | --- |
| `index.html` | The page: countdown, calendar reminder, WhatsApp share, Instagram |
| `og.png` | Preview image for WhatsApp and other link shares |
| `CNAME` | Custom domain for GitHub Pages (`polbazaar.com`) |
| `404.html` | Sends any other address back to the countdown |
| `.nojekyll` | Serve the files as they are |

Preview the live state with `?preview=live`.
